# 声の避難ガイド（koe-hinan）

圏外でも地名を正しく読む、声の避難ガイド。スマートフォンのブラウザの中だけで、いる場所の洪水の浸水想定と、洪水に対応した近くの指定緊急避難場所を選び、地名や施設名を正しい読みで声にして伝える Web アプリです。アーバンデータチャレンジ 2026 への応募作品として作っています（制作中）。

## 使うデータ

- 練馬区「指定緊急避難場所一覧」（CC BY 4.0）
- 国土地理院「指定緊急避難場所データ」（国土地理院コンテンツ利用規約）
- 国土交通省 国土数値情報「洪水浸水想定区域データ（河川単位）」（CC BY 4.0）
- デジタル庁「アドレス・ベース・レジストリ 町字データ」（公共データ利用規約 第1.0版）

指定緊急避難場所・指定避難所のデータは市町村が登録したもので、最新でない場合や載っていない場合があります。最新の状況は必ず区市町村で確かめてください。

## ライセンス

アプリのコードは Apache-2.0。データと音声モデルはそれぞれの提供元の条件に従います。
