# 声の避難ガイド（koe-hinan）

圏外でも地名を正しく読む、声の避難ガイド（練馬区・洪水）。スマートフォンのブラウザの中だけで、いる場所の洪水の浸水想定と、洪水に指定された近くの指定緊急避難場所を選び、施設名を正しい読みで声にして伝える Web アプリです。アーバンデータチャレンジ 2026 の応募作品です。

- **実行サイト**: https://ayutaz.github.io/koe-hinan/
- **デモ動画（約2分・音声あり）**: https://ayutaz.github.io/koe-hinan/demo/demo.mp4

## 使い方

1. 通信のある所で開き、「準備する」を押す（アプリ・データ・声で約140MB。Wi-Fi で）
2. あとは機内モード・圏外でも、「今いる場所で案内する」「地図で選ぶ」「町から選ぶ」で案内と読み上げが動きます

練馬区の外にいるときは、地図か町の一覧から場所を選んでください。

## 何をしているか

- 練馬区の指定緊急避難場所 163件（洪水の指定 154件）から、**洪水に指定された場所だけ**を直線距離の近い順に3つ選びます
- 国土数値情報の洪水浸水想定区域（石神井川・神田川・想定最大規模）で、その場所の浸水の深さと、家屋倒壊等氾濫想定区域に入るかを判定します
- 案内の文は、画面用は漢字、読み上げ用は施設名と川の名前を読み仮名にして、[piper-plus](https://github.com/ayutaz/piper-plus)（ONNX・WebAssembly）で端末の中で音声にします。現在地をサーバーに送る処理はありません

### 施設名の読み仮名

練馬区の「指定緊急避難場所一覧」の `名称_カナ` は、2026-11-19 時点で163件すべて空欄でした。同じ区の「AED設置箇所一覧」「投票所一覧」の読み仮名を突き合わせ、163件すべての読みを、出どころと一緒に [`data/readings.csv`](data/readings.csv) にまとめました。

| 読みの決め方 | 件数 |
|---|---:|
| 区の2つのデータで読みが一致 | 65 |
| 区のデータのどちらか1つにある読み | 89 |
| 食い違い・字体の違いを、理由を書いて決めた | 3 |
| 町名の読みと一般語から組み立てた | 6 |

施設名を漢字のまま音声合成（piper-plus の読みの処理）に渡すと、**163件のうち29件で読みが変わります**（谷原小学校→たにはら・向山小学校→むかいやま・小竹小学校→こだけ など。結果は [`data/g2p_report.json`](data/g2p_report.json)）。

## 作り直す・確かめる

```sh
npm install
sh tools/fetch_data.sh          # 元データを data/raw/ に取る（国土地理院のデータは利用上の注意に同意して手で取る）
uv run --no-project --with shapely python tools/build_data.py   # public/data/ と data/readings.csv を作る
node tools/check_g2p.mjs        # 漢字のままの読みと読み仮名の読みを比べる
npm test                        # 単体テスト
npm run build && npx playwright test   # 通信を切った状態のブラウザのテスト（Chrome）
```

デモ動画は `node tools/record_demo.mjs && uv run --no-project python tools/compose_demo.py` で作り直せます（ffmpeg が要ります）。

## 使うデータ

- 練馬区「指定緊急避難場所一覧」「AED設置箇所一覧」「投票所一覧」（CC BY 4.0）
- 国土地理院「指定緊急避難場所データ」（国土地理院コンテンツ利用規約）
- 国土交通省 国土数値情報「洪水浸水想定区域データ（河川単位）2024年度」（CC BY 4.0）
- デジタル庁「アドレス・ベース・レジストリ 町字データ」（公共データ利用規約 第1.0版）
- 背景の地図: 地理院タイル（通信があるときだけ）
- 声: Piper Plus:つくよみちゃん（[モデルと利用条件](https://huggingface.co/ayousanz/piper-plus-tsukuyomi-chan)・[つくよみちゃんコーパスの規約](https://tyc.rei-yumesaki.net/material/corpus/#terms3)）

指定緊急避難場所のデータは市町村が登録したもので、最新でない場合や載っていない場合があります。最新の状況は必ず練馬区で確かめてください。この案内は、ほかの川・内水氾濫・土砂災害の想定を含みません。距離と方角は直線です。
